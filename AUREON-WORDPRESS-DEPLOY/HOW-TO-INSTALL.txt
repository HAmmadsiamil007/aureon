STEP-BY-STEP INSTALLATION
=========================

1. UPLOAD FRONTEND ENGINE (REQUIRED — DO THIS FIRST)
   --------------------------------------------------
   ⚠️  THIS IS THE #1 CAUSE OF FATAL ERRORS IF MISSED.

   a) FILE MANAGER METHOD (InfinityFree):
      - Go to InfinityFree File Manager
      - Navigate to: htdocs/wp-content/
      - Upload the ENTIRE "frontend/" folder here
      - Result: htdocs/wp-content/frontend/views/loader.php must exist
      - Set permissions: chmod 755 for folders, 644 for files

   b) FTP METHOD:
      - Upload "frontend/" folder to: wp-content/frontend/
      - Do NOT put it inside themes/aureon/
      - Verify: wp-content/frontend/views/loader.php exists

   c) COMMON MISTAKE TO AVOID:
      ❌ DO NOT upload frontend/ to wp-content/themes/aureon/frontend/
      ✅ DO upload frontend/ to wp-content/frontend/

2. UPLOAD THEME (REQUIRED)
   -------------------------
   a) FILE MANAGER METHOD (InfinityFree):
      - Navigate to: htdocs/wp-content/themes/
      - DELETE the old "aureon" folder completely
      - Upload the new "aureon" folder
      - Set permissions: chmod 755 for folders, 644 for files

   b) FTP METHOD:
      - Delete old aureon/ folder from wp-content/themes/
      - Upload the entire "aureon" folder to: wp-content/themes/

   c) WORDPRESS ADMIN METHOD:
      - Zip the "aureon" folder into "aureon-theme.zip"
      - WordPress Admin → Appearance → Themes → Add New → Upload Theme
      - Upload aureon-theme.zip → Install → Activate
      NOTE: This may not work on all hosts due to upload limits.

3. UPLOAD PLUGIN (REQUIRED)
   -------------------------
   a) FILE MANAGER METHOD:
      - Navigate to: htdocs/wp-content/plugins/
      - Upload the "aureon-studio" folder
      - WordPress Admin → Plugins → Activate "Aureon Studio"

   b) ZIP METHOD:
      - Zip "aureon-studio" folder into "aureon-studio.zip"
      - WordPress Admin → Plugins → Add New → Upload Plugin
      - Upload aureon-studio.zip → Install → Activate

4. UPLOAD MU-PLUGIN (REQUIRED)
   ----------------------------
   - Copy "mu-plugins/aureon-fix-wc-session.php" to: wp-content/mu-plugins/
   - This auto-activates (no admin action needed)
   - Fixes WooCommerce session handling for cart bridge

5. CONFIGURE DESIGN PACK
   ----------------------
   - WordPress Admin → Appearance → Customize → AETHER Design
   - Vineta is now the DEFAULT active design (no manual selection needed)
   - Set Homepage to display static front page

   If you need to explicitly set Vineta:
   - Option: aether_active_design = 'vineta'
   - Or constant: define('AETHER_DESIGN', 'vineta');

6. VERIFY INSTALLATION
   --------------------
   Visit these pages and confirm they load:
   - Homepage: yoursite.com/
   - Shop: yoursite.com/shop/
   - Product: yoursite.com/product/
   - Cart: yoursite.com/cart/
   - Checkout: yoursite.com/checkout/
   - Account: yoursite.com/my-account/
   - Blog: yoursite.com/blog/
   - Contact: yoursite.com/contact/

   If any page shows a blank screen or fatal error, see TROUBLESHOOTING below.

EXPECTED RESULT
===============
- All pages load with Vineta presentation (multipurpose eCommerce)
- No Shopify/third-party calls in browser console
- Cart/checkout work through WooCommerce
- Demo products visible when no real WC products exist
- Real products replace demo automatically
- Mobile responsive at 1440, 1024, 768, 390 viewports
- ZERO Ferm Living references in active runtime

DEMO SYSTEM
===========
The Vineta demo system provides:

DEMO DATA:
- Demo products across multiple categories
- Demo collections
- Local image assets (no remote CDN dependency)

DEMO↔REAL TRANSITION:
- 0 real WC products → demo products visible
- 1+ real WC products → ALL demo products hidden
- Delete all real products → demo products return

DEMO MODES:
- auto (default) → Shows demos when no real content, hides when real exists
- force_demo → Always shows demo content
- disabled → Hides all demo content

DEMO SAFETY:
- Demo products: purchasable: false
- Demo products never enter cart/checkout/orders
- Real WooCommerce products remain fully functional

TROUBLESHOOTING
===============

"Failed opening required .../frontend/views/loader.php"
→ FATAL: frontend/ is at wrong location
→ FIX: Upload frontend/ to wp-content/frontend/ (NOT inside themes/aureon/)
→ Verify: wp-content/frontend/views/loader.php must exist

Blank page / Fatal error
→ Check PHP error log, ensure PHP 8.0+
→ Verify frontend/ is at wp-content/frontend/ (see above)
→ Verify theme is at wp-content/themes/aureon/

Images not loading
→ Vineta uses local assets (no remote CDN)
→ Real product images need to be uploaded via WooCommerce

Cart not working
→ Ensure WooCommerce is activated
→ Ensure mu-plugin is in wp-content/mu-plugins/

CSS not loading
→ Check browser console for 404s
→ Verify wp-content/frontend/designs/vineta/css/ exists

Textdomain notice (_load_textdomain_just_in_time)
→ Non-fatal, does not affect functionality
→ Can be ignored
