A token-driven premium frontend framework for WordPress. Fully standalone — no parent theme required. Fast, accessible (WCAG 2.2 AA ready), and extensible.

== Description ==

Lumina is a premium WordPress theme engineered for speed, accessibility, and long-term maintainability. It is delivered as a complete, standalone theme — it does not depend on any parent theme or third-party framework.

Key features:

* Token-driven design system — every color, spacing, radius, and motion value ships as a CSS custom property, giving you consistent theming and dark mode support.
* Component & template architecture — reusable, configurable frontend components assembled into full templates with zero duplicated markup.
* Render engine with result caching — composable view models, data adapters, and layout composition with a render cache for fast page loads.
* Built-in asset pipeline — Vite-powered CSS/JS builds with hashed filenames, cache busting, and conditional loading.
* Animation engine — GSAP, Lenis smooth scroll, and Three.js integrations with full reduced-motion support and performance safeguards.
* Accessibility-ready — semantic HTML, keyboard navigation, focus states, skip links, ARIA landmarks, and accessible dialogs, accordions, tabs, and menus (WCAG 2.2 AA targets).
* WooCommerce-compatible — product, shop, cart, checkout, and account pages integrate through official WooCommerce extension points. HPOS and WooCommerce Blocks compatible.
* Plugin-safe — graceful degradation when third-party plugins (SEO, forms, page builders, etc.) are absent.
* RTL-ready and translation-ready — full text domain and locale-friendly markup.

== Installation ==

1. In your WordPress admin, go to Appearance > Themes > Add New.
2. Click "Upload Theme" and select the `lumina.zip` file.
3. Click "Install Now", then "Activate".
4. (Recommended) Install and activate the companion plugin, **Lumina Companion**, to unlock the full premium feature set: spacing, typography, page header, secondary navigation, menu plus, sections, site library, WooCommerce, colors, backgrounds, blog, copyright, disable elements, elements, font library, hooks, and general layout controls.

== Frequently Asked Questions ==

= Does Lumina require a parent theme? =

No. Lumina is a fully standalone theme with no parent-theme dependency. It runs directly on WordPress core.

= Does Lumina require the companion plugin? =

No. The theme works without it. The companion plugin is optional and adds premium feature categories on top of the same design-token architecture.

= Is WooCommerce supported? =

Yes. Shop, product, cart, checkout, and account templates are integrated through official WooCommerce extension points, preserving every WooCommerce hook. HPOS and WooCommerce Blocks are supported.

= Is dark mode supported? =

Yes. The design-token system provides light and dark palettes via CSS custom properties.
