# ADR-002 — Naming Conventions

- **Status:** Accepted
- **Date:** 2026-08-03

## Context

Collision-safe, grep-safe naming across theme, framework, and WP surface.

## Decision

- Namespace: `Lumina\Core\`
- Global function prefix: `lumina_`
- Option prefix: `lumina_`
- Hook prefix: `lumina_` (domain events `lumina_core:*`, ADR-006)
- Asset handles: `lumina-*`
- Feature flags: `lumina_feature_*`

## Consequences

No global leaks; matches WP Core conventions; the CI can enforce prefix hygiene
via PHPCS `PrefixAllGlobals`.
