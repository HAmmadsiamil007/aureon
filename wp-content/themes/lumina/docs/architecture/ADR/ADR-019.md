# ADR-019 — Phase 8 Plugin Bridges

- **Status:** Accepted
- **Date:** 2026-08-04
- **Phase:** 8 (Plugin Bridges)

## Context

Lumina must coexist with the site's plugin ecosystem (WooCommerce deferred to
Phase 9, plus 12 more) without ever calling a vendor symbol unguarded,
modifying plugin code, or coupling the framework to any third-party
implementation. ADR-007 established "bridges are capability adapters; plugins
untouched". Phase 8 ships that architecture for: ACF, Rank Math, Yoast, WPML,
Polylang, Fluent Forms, Gravity Forms, WPForms, BuddyPress, bbPress, LearnDash,
and The Events Calendar.

## Decision

1. **Contract:** `BridgeInterface` (slug, name, `is_active`, version,
   capabilities, `supports`); `Bridge` is the shared base implementing
   `supports()` and guarded detection helpers (`guard()` — `class_exists`/
   `function_exists` first, `constant_version()`).
2. **Laziness:** `Bridges\Registry` maps slug → factory closure; bridges are
   constructed exactly once on first `get()` (memoized). `BridgeManager`
   (`get`/`all`/`active`/`is_active`/`supports`) is the only public surface.
3. **Source of truth:** `app/Bridges/config/plugins.php` (typed) defines the
   matrix — name, plugin file path, capabilities. `FeatureMatrix` reads it;
   `docs/plugins.md` mirrors it for humans.
4. **Health:** `HealthCheck` uses the public WP APIs (`is_plugin_active()`,
   `get_plugins()`) when present, returns inert answers WP-free, and applies
   minimum-version floors (`passes()`). Inactive plugins never pass.
5. **Safety policy:** every vendor call is capability-guarded first; absent
   plugins resolve to inactive bridges and every adapter method returns a safe
   default (empty array / `''` / `null` / `false`). Lumina never throws.
6. **Wiring:** `BridgesServiceProvider` registers `bridges.registry`,
   `bridges.manager`, `bridges.matrix`, `bridges.health`. Bridges are passive —
   nothing is booted, no hooks installed, no assets enqueued.

## Consequences

- Third-party plugins are reached exclusively through typed, guarded facades.
- Bridge surface is enumerable (matrix) and testable WP-free (smoke-phase8).
- WooCommerce gets its own deeper treatment in Phase 9 on the same contract.
- Adding a plugin later = one matrix entry + one adapter class.
