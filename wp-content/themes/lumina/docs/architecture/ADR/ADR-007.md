# ADR-007 — Bridges Are Capability Adapters

- **Status:** Accepted
- **Date:** 2026-08-03

## Context

Lumina must not reference vendor classes directly; plugins must stay untouched.

## Decision

Every vendor integration is a **bridge** (`Lumina\Core\Bridges\*`): a single
choke point with version floors, feature detection, and sanitized data shaping.
WooCommerce (Phase 9) re-emits every `woocommerce_*` hook it replaces.

## Consequences

Lumina never calls vendor methods unguarded (`function_exists` /
`class_exists` guards); uninstalled plugins never break the theme.
