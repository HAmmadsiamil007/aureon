# ADR-010 — Caching: WP Transients + Object-Cache Abstraction

- **Status:** Accepted
- **Date:** 2026-08-03

## Context

Tokens, nav fragments, and render output need tag/slug-scoped, purgeable,
update-safe caching.

## Decision

Cache through WP Transients + an object-cache abstraction (`Cache\*`, Phase 2)
with **tagged keys** (`CacheKey` namespace = source + version). Purge on
`save_post`, menu, and widget changes.

## Consequences

Cache invalidation is scoped, not global; API level in `Version` is embedded in
keys so stale caches cannot survive upgrades.
