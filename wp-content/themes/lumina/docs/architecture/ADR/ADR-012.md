# ADR-012 — Quality Tooling & Testing Stack

- **Status:** Accepted
- **Date:** 2026-08-03

## Context

Enterprise-grade code requires enforced standards and a real test pyramid.

## Decision

- PHPCS (WordPress Coding Standards) + PHPStan **level 5** + Psalm **errorLevel 5**.
- Unit/integration tests via PHPUnit + `WP_Mock`/`Brain Monkey`; E2E via
  Playwright (Chromium) — full stack lands in Phase 15.
- CI gates run on every push/PR (`.github/workflows/ci.yml`).

## Consequences

Enforced in Phase 0 (tooling) and continuously from Phase 1 onward; the test
suites themselves arrive in Phase 15 per the plan.
