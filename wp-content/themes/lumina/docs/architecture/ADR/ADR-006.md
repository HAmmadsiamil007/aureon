# ADR-006 — Domain Events vs WP Actions

- **Status:** Accepted
- **Date:** 2026-08-03

## Context

Unambiguous separation between the framework's internal event bus and the
WordPress action surface.

## Decision

Domain events use the singular `lumina_core:*` double-colon namespace
(`lumina_core:booting`, `lumina_core:booted`, `lumina_core:ready`,
`lumina_core:boot_error`). WP-boundary hooks keep the `lumina_*` prefix.

## Consequences

Clear bus-vs-boundary separation; the Event Dispatcher (Phase 2) forwards
relevant WP actions into the domain bus, never the reverse.
