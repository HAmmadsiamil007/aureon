# ADR-001 — Lumina Is a GeneratePress Child Theme

- **Status:** Accepted
- **Date:** 2026-08-03

## Context

The premium frontend must coexist with GeneratePress 3.6.1 + GP Premium 2.5.6
(which hard-check the active theme template slug `generatepress`) while staying
update-safe and winning the WP template hierarchy.

## Decision

Deliver the frontend as a **child theme** (`Template: generatepress`) plus an
optional companion mu-plugin for asset/token concerns. Never fork, never patch.

## Consequences

- GP + GP Premium keep auto-updating; `get_stylesheet()` semantics preserved.
- Child templates win in the template hierarchy; Gutenberg/editor integration retained.
- All custom code must live inside the child theme; parent files are untouchable.
