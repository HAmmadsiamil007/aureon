# ADR-011 — Environment Configuration

- **Status:** Accepted
- **Date:** 2026-08-03

## Context

Standard WP environment detection plus per-environment overrides, feature flags,
and debug mode — with no dotenv dependency.

## Decision

Base detector is `wp_get_environment_type()`. Optional `lumina.env.json`
(git-ignored; template `lumina.env.json.example`) overrides env, feature flags,
debug, and Vite dev-server settings. Secrets never enter the repo or logs.

## Consequences

Implemented in Phase 1 (`Support\Env` + `ConfigLoader`); `lumina.env.json`
values are merged over defaults; config loader rejects `../` traversal.
