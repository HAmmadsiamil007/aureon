# ADR-005 — Vite Build Pipeline

- **Status:** Accepted
- **Date:** 2026-08-03

## Context

Modern SCSS→CSS and TS/ESM→JS compilation with dev HMR, cache busting, and no
runtime build step.

## Decision

Use **Vite** (pinned 6.4.x) for assets: SCSS→CSS, ES modules, JSON manifest,
`php-vite`-style runtime asset loader. Dev server port via `LUMINA_VITE_PORT` /
`lumina.env.json`.

## Consequences

`assets-src/` compiles to `assets/dist/` (git-ignored); manifest drives cache
busting (Phase 7); zero runtime build dependency on the server.
