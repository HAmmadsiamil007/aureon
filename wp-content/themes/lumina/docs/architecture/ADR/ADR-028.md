# ADR-028 — Lumina Companion plugin: original implementation

- **Status:** Accepted
- **Date:** 2026-08-04
- **Phase:** 16 (Safe Rebranding)

## Context

The premium feature categories formerly provided by a third-party commercial
add-on must be delivered as **Lumina's own plugin** that works with the Lumina
theme. Legal boundary: the commercial add-on is not GPL and cannot be renamed
or redistributed as Lumina's own product; every feature category is therefore
re-implemented as 100% original code.

## Decision

1. **New plugin:** `wp-content/plugins/lumina-companion/`, GPL-2.0-or-later,
   PSR-4 `Lumina\Companion\` → `src/`, version 1.0.0, zero runtime Composer
   dependencies (spl_autoload fallback).
2. **Modules (all original):**
   - `Spacing` — container/gutter/section/card/gap tokens.
   - `Typography` — font family/size/weight/line-height tokens.
   - `PageHeader` — configurable page-header region via the composition
     pipeline.
   - `SecondaryNav` — secondary menu location + slim bar (public
     `wp_nav_menu`).
   - `MenuPlus` — mega-menu support for `menu-item-mega` items.
   - `Sections` — content regions on the public `lumina_*` shell hooks.
   - `SiteLibrary` — presets REST endpoint (guarded).
   - `WooCommerce` — WC styling via public hooks only, active only when
     WooCommerce exists; no WC hook removed.
3. **Theme gating:** the plugin boots its features only when the active theme
   is `lumina` (`get_template() === 'lumina'`); it degrades to a no-op on any
   other theme.
4. **Integration:** the theme fires the region hooks; the plugin fills them
   and injects settings through the `lumina_template_data` filter.
5. **Verification:** `bin/smoke-phase16-plugin.php` (17 assertions) +
   `bin/smoke-phase16-integration.php` (16 assertions), both WP-free; PHPCS
   - PHPStan level 5 clean.

## Consequences

- Lumina ships a complete, legal, ownable premium feature set.
- No commercial code is copied, renamed, or redistributed.
- The plugin works with the theme out of the box and never breaks when the
  theme is switched.
