# ADR-004 — Public WP/GP APIs Only + CI Hash-Gate

- **Status:** Accepted
- **Date:** 2026-08-03

## Context

Update safety requires never depending on GP internals or shipping modified
parent files.

## Decision

- Use only public WP APIs and documented `generate_*` hooks/filters
  (`generate_get_option()`, `apply_filters('generate_*')`, `do_action('generate_*')`,
  `wp_nav_menu`, widgets, template hierarchy).
- Path resolution via `get_stylesheet_directory()` — never `get_theme_roots()`.
- CI hashes the GeneratePress + GP Premium directories and **fails the build** if
  any shipped file differs from the audited baseline.

## Consequences

Enforced by `bin/verify-parent-integrity.sh` (473/473 files, positive + negative
tests). Implemented in Phase 0.
