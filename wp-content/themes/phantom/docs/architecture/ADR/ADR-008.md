# ADR-008 — Rebranding Is Planning-Only

- **Status:** Accepted
- **Date:** 2026-08-03

## Context

Brand changes are content-level; renaming PHP namespaces, options, hooks, and
DB keys is a breaking API change.

## Decision

Phase 16 delivers a **rebrand plan only** — no implementation until every CSS
class, option key, hook, and data map is audited. All renames ship behind
feature flags.

## Consequences

UI/UX-level brand changes are safe immediately; structural renames are deferred
and gated.
