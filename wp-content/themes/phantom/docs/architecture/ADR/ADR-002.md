# ADR-002 — Naming Conventions

- **Status:** Accepted
- **Date:** 2026-08-03

## Context

Collision-safe, grep-safe naming across theme, framework, and WP surface.

## Decision

- Namespace: `Phantom\Core\`
- Global function prefix: `phantom_`
- Option prefix: `phantom_`
- Hook prefix: `phantom_` (domain events `phantom_core:*`, ADR-006)
- Asset handles: `phantom-*`
- Feature flags: `phantom_feature_*`

## Consequences

No global leaks; matches WP Core conventions; the CI can enforce prefix hygiene
via PHPCS `PrefixAllGlobals`.
