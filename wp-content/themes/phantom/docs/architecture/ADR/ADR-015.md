# ADR-015 — Phase 3 Design Token Engine

- **Status:** Accepted
- **Date:** 2026-08-03
- **Phase:** 3 (Design Token Engine)

## Context

Every later subsystem (Render Engine, Components, Asset Pipeline, Animation)
needs a single, typed source of presentational values. The plan (§Phase 3)
mandates a token system with presets, inheritance, and per-scope CSS variable
generation, so components never hard-code colors/spacing/type (ADR-003).

## Decision

1. **Canonical groups** (`app/Tokens/config/tokens.php`): `color`,
   `typography`, `space` (4px scale), `radius`, `shadow`, `motion`, `layout`,
   `grid`, `breakpoints`, `z-index`, `component` — matching the plan §Phase 3
   canonical section. Space tokens are named by px value (`space.4` = `0.25rem`,
   the plan's acceptance example).
2. **Pipeline:** `TokenSource` parses nested definitions into a flat dot-map;
   `Preced` collects layers in precedence order (default → preset → override);
   `Resolver` walks the `extends` inheritance graph; `TokenFactory` maps tokens
   to CSS custom-property names (`--phantom-{name}` with dots → hyphens);
   `CssRenderer` emits `:root` + `[data-phantom-theme="<preset>"]` blocks.
   `Invariant` enforces name safety and WCAG AA contrast.
3. **Data files:** canonical defaults + presets (`default`, `dark`) are PHP
   arrays under `app/Tokens/config/`; the `Loader\DataProvider` caches them in
   memory. Phase 7 swaps the render path to a static `tokens.css` build without
   changing the repository API (ADR-005).
4. **Exposure:** `TokenServiceProvider` binds all token services into the
   container (registered in `Config\config.php` `providers`); consumers use
   `App::make('tokens.repository')` → `TokenRepository`.
5. **Security:** token names must match `/^[a-z0-9][a-z0-9\-]{0,63}$/` per
   dot-segment. The plan's sample pattern started segments with a letter, but
   canonical numeric-scale tokens (`space.4`, `type.size.2xl`) require a leading
   digit; the CSS var prefix (`--phantom-`) guarantees the full property name
   still starts with a letter. The security intent — no dots/quotes/braces/
   uppercase ever reaching a selector or declaration — is fully preserved.

## Consequences

- Components consume `App::make('tokens.repository')->token('color.accent')`
  instead of magic values (ADR-003).
- Presets are data-only: a new theme preset is a new array entry, no code.
- Contrast is CI-checkable (smoke suite asserts 4.5:1 for default + dark).
- No runtime CSS generation per request in Phase 3 — rendering is on-demand
  and memoized; static emission lands with Phase 7.
