# ADR-013 — Phase 1 Bootstrap Architecture

- **Status:** Accepted
- **Date:** 2026-08-03
- **Phase:** 1 (Bootstrap)

## Context

Phantom Core must boot deterministically from the child theme without touching
GeneratePress, before GP Premium and third-party plugins, using only public APIs.

## Decision

1. **Single entry:** `functions.php` (Phase 0) requires `app/load.php`, which
   registers the Composer autoloader (if readable) and binds
   `Boot\Kernel::launch()` to `plugins_loaded` at **priority 5** — never earlier
   or later (ADR-004).
2. **Kernel lifecycle:** `Kernel::launch()` → `bootstrap()` runs the ordered
   `Sequencer`: `config → env → flags → logger → errorHandler`, guarded by
   `phantom_core:booting` / `phantom_core:booted` / `phantom_core:ready`
   events (ADR-006). Failures raise `phantom_core:boot_error` and are logged —
   never rethrown on the WP surface.
3. **App facade:** `Phantom\Core\Core\App` is the public static entry:
   `instance()`, `make()`, `get()`, `env()`, `isDebug()`, `log()`. It holds the
   Phase-1 service registry; the full DI `Container\Container` lands in Phase 2.
4. **Config:** `Config\ConfigLoader` returns an immutable array (defaults +
   `phantom.env.json` overrides, ADR-011). No dotenv, no `../` traversal.
5. **Services:** `Support\Env` (wraps `wp_get_environment_type()`),
   `Support\FeatureFlags` (reads `features` map), `Support\Debug\Log` facade +
   `Loggers` (PSR-3-ish levels, redacts `ph_pass`/`sku_key`), and
   `Support\ErrorHandler` (wraps `WP_Error`, registers once).
6. **Testability:** a WP-free CLI smoke suite (`bin/smoke-phase1.php`) drives the
   full boot lifecycle in CI without a live WordPress install.

## Consequences

- Deterministic, documented boot order; other plugins can compose via
  `Sequencer` filters (Phase 1 exposes `phantom_core:boot_steps`).
- No runtime cost until `plugins_loaded(5)`; boot target ≤ 3 ms self-time.
- Phase 2 slots in cleanly: providers register via the same Sequencer; the
  `App` registry is superseded by `Container\Container` without breaking
  `App::make()` consumers.
