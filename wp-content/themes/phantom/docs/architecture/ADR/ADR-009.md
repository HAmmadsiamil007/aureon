# ADR-009 — PSR-4 Autoload via Composer

- **Status:** Accepted
- **Date:** 2026-08-03

## Context

Namespaced framework code needs deterministic autoloading with no external PHP
runtime dependencies.

## Decision

Composer PSR-4 mapping `Phantom\Core\` → `app/`. `functions.php` → `app/load.php`
registers the Composer autoloader (built by the project-local toolchain).

## Consequences

Implemented in Phase 0 (`composer.json`); `composer dump-autoload --optimize`
yields 2229 classes; class files in `app/` follow namespace-matching names
(PHPCS filename sniff scoped out of `app/` accordingly).
