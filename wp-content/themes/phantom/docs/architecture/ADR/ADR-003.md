# ADR-003 — No Magic Numbers: Design Tokens as CSS Custom Properties

- **Status:** Accepted
- **Date:** 2026-08-03

## Context

Theme presets, accessibility contrast, and responsive behavior must be data, not
hard-coded values sprinkled through components.

## Decision

All presentational values (color, type, space, radius, shadow, motion, z-index)
are **design tokens** emitted as CSS custom properties (`--phantom-*`).
Components never hard-code hex/px.

## Consequences

Theming/presets and WCAG contrast become data changes; token engine lands in
Phase 3; `prefers-reduced-motion` becomes a token-consuming media query.
