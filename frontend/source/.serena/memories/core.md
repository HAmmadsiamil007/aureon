## Structure

## Invariants
- Pure HTML/CSS/JS frontend — no framework, no bundler
- Designed for WordPress/WooCommerce integration (PHANTOM Core plugin)
- Visual Customizer 2.0 is the active transformation: click-to-edit replaces traditional WP Customizer
- Parent directory contains phantom-core PHP plugin (WordPress)
