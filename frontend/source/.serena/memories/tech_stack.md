# phantom-frontend tech stack

- **Markup:** HTML5 semantic
- **Styling:** SCSS/CSS
- **Scripting:** Vanilla JS
- **Backend:** WordPress 6.4 + WooCommerce 8.5 (parent dir)
- **PHP Plugin:** PHANTOM Core v2.0.0 (parent dir)
- **Database:** MySQL 8.0 (Docker)
- **Server:** Apache (Docker, port 8080)
- **WP Admin:** http://localhost:8080/wp-admin (admin / admin123)
- **No JS framework, bundler, or task runner in frontend dir**
