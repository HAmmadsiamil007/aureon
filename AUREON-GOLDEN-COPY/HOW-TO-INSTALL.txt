PREREQUISITES

STEP-BY-STEP INSTALLATION
=========================

1. UPLOAD THEME (REQUIRED)
   -------------------------
   The theme is now self-contained. No separate frontend/ upload needed.

   a) FILE MANAGER METHOD (InfiniteFree):
      - Go to InfinityFree File Manager
      - Navigate to: htdocs/wp-content/themes/
      - DELETE the old "aureon" folder completely
      - Upload "aureon-theme-fixed.zip"
      - Extract it (so "aureon/" folder is directly under themes/)
      - Set permissions: chmod 755 for folders, 644 for files

   b) FTP METHOD:
      - Delete old aureon/ folder from wp-content/themes/
      - Upload the entire "aureon" folder to: wp-content/themes/
      - Ensure folder permissions are 755 and files are 644

   c) WORDPRESS ADMIN METHOD:
      - Zip the "aureon" folder into "aureon-theme.zip"
      - WordPress Admin → Appearance → Themes → Add New → Upload Theme
      - Upload aureon-theme.zip → Install → Activate
      NOTE: This may not work on all hosts due to upload limits.

2. UPLOAD PLUGIN (REQUIRED)
   -------------------------
   a) FILE MANAGER METHOD:
      - Navigate to: htdocs/wp-content/plugins/
      - Upload the "aureon-studio" folder
      - WordPress Admin → Plugins → Activate "Aureon Studio"

   b) ZIP METHOD:
      - Zip "aureon-studio" folder into "aureon-studio.zip"
      - WordPress Admin → Plugins → Add New → Upload Plugin
      - Upload aureon-studio.zip → Install → Activate

3. UPLOAD MU-PLUGIN (REQUIRED)
   ----------------------------
   - Copy "mu-plugins/aureon-fix-wc-session.php" to: wp-content/mu-plugins/
   - This auto-activates (no admin action needed)
   - Fixes WooCommerce session handling for Ferm Living cart bridge

4. INSTALL SAMPLE PRODUCTS (RECOMMENDED)
   ---------------------------------------
   a) Upload "install-ferm-products.php" to your WordPress root (next to wp-config.php)
   b) Visit: https://yoursite.com/install-ferm-products.php
   c) Click "Install Products" button
   d) The script will create:
      - 3 categories: Furniture, Lighting, Accessories
      - 10 sample products matching Ferm Living HTML pages
      - WordPress navigation menus
      - WooCommerce pages (shop, cart, checkout, my-account)
   e) DELETE install-ferm-products.php after installation

   MANUAL PRODUCT SETUP (if you prefer):
   - WC Admin → Products → Add New
   - Set slug to match Ferm HTML filename (e.g., "meridian-lamp-black")
   - Set images, prices, categories
   - Ferm Living maps WC products to its frozen presentation

5. CONFIGURE DESIGN PACK
   ----------------------
   - WordPress Admin → Appearance → Customize → AETHER Design
   - Select "Ferm Living" as active design
   - Set Homepage to display static front page

6. FLUSH OPCACHE (if enabled)
   ---------------------------
   - If server has OPcache: restart PHP or run:
     php /tmp/flush_opcache.php
   - Or restart your web server

7. VERIFY INSTALLATION
   --------------------
   Visit these pages and confirm they load:
   - Homepage: yoursite.com/
   - Product: yoursite.com/product/meridian-lamp-black/
   - Collection: yoursite.com/product-category/lighting/
   - Cart: yoursite.com/cart/
   - Checkout: yoursite.com/checkout/
   - Contact: yoursite.com/contact/

EXPECTED RESULT
===============
- All pages load with Ferm Living presentation (Danish design aesthetic)
- No Shopify/third-party calls in browser console
- Cart/checkout work through WooCommerce
- Some product images may show as placeholders (see KNOWN ISSUES)
- Mobile responsive at 1440, 1024, 768, 390 viewports

KNOWN NON-BLOCKING ISSUES
==========================
- Product images: Some images reference Shopify CDN paths that won't load
  on WordPress. The page structure renders correctly but images may appear
  broken. To fix: re-upload product images via WooCommerce → Products.
- cartProductFlags JS error: Shopify dead code in app.js, caught gracefully
- Some images use display:none (Ferm lazy-load behavior, loads on scroll)
- Language selector: single-store mode (no multi-language configured)

TROUBLESHOOTING
===============
- Blank page / Fatal error:
  → Check PHP error log, ensure PHP 8.0+
  → Verify "frontend/views/loader.php" exists inside aureon/ folder
  → The theme MUST be self-contained (frontend/ inside aureon/)

- "Failed opening required .../frontend/views/loader.php":
  → You uploaded the OLD theme without the bundled frontend/ folder
  → Delete and re-upload using aureon-theme-fixed.zip

- Images not loading:
  → Product images need to be re-uploaded via WooCommerce
  → CDN assets (fonts, CSS, JS) load from the theme automatically

- Cart not working:
  → Ensure WooCommerce is activated
  → Ensure mu-plugin is in wp-content/mu-plugins/

- CSS not loading:
  → Check browser console for 404s
  → Verify aureon/ folder structure is intact
